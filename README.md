# Movie API 🎬

API REST desenvolvida com FastAPI e SQLAlchemy.

## 📌 Funcionalidades
- Criar filmes
- Listar filmes
- Buscar filme por ID
- Atualizar filmes
- Deletar filmes

## 🛠️ Tecnologias
- FastAPI
- SQLAlchemy
- MySQL
- Python

## 🚀 Como rodar

1. Instalar dependências:
pip install -r requirements.txt

2. Rodar aplicação:
uvicorn main:app --reload

## 📂 Estrutura
- models → tabelas do banco
- schemas → validação de dados
- routes → endpoints
- database → conexão com banco
